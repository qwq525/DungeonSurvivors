# 《地牢幸存者》技术文档

> 版本 v0.2 · 2026-10-26 · 对应 Unity 2022.3.62f3c1

## 1. 架构分层

```
表现层 (UI / VFX / 音效)
    ▲ 订阅事件
逻辑层 (Player / Enemy / Weapon / Progression / Flow)
    ▲ 读写
数据层 (ScriptableObject 配置 / SaveSystem / EventBus / ObjectPool)
```

三条规定：
1. **逻辑层不引用 UI**：伤害/死亡/升级只发事件，UI 订阅；
2. **数值进配置**（目标态）：后续把武器/敌人/波次数值迁到 ScriptableObject；
3. **高频创建对象走对象池**：敌人 / 子弹 / 经验宝石 / 伤害数字。

## 2. 核心模块

### 2.1 EventBus（事件总线）
- 静态 `Dictionary<Type, Delegate>`，`Subscribe<T>/Unsubscribe<T>/Publish<T>`。
- UI/音效/统计通过订阅解耦；场景重载时 `GameManager.RestartRun/GoToMenu` 调用 `EventBus.Clear()` 清理残留订阅。
- 面试追问：订阅退订成对、静态持有委托导致泄漏、事件参数用 struct 减少 GC。

### 2.2 ObjectPool（对象池）
- 泛型 `ObjectPool<T> where T : Component`：预热、容量上限、池根节点、`IPoolable.OnSpawn/OnDespawn` 重置。
- 敌人/子弹/宝石/伤害数字均由各自 Spawner 持有池。
- 面试追问：回收要重置哪些状态（血量/速度/协程/事件订阅/父节点/激活态）、池上限策略、池对象泄漏。

### 2.3 玩家与战斗
- `PlayerController`：Update 采样输入、FixedUpdate 设速度、斜向归一化；`IInputSource` 抽象键盘/触屏。
- `DashAbility`：冲刺时长/冷却/无敌帧计时器（非协程，避免对象禁用后悬挂）。
- `MissileWeapon`：冷却 + 最近敌人索敌（当前遍历 `EnemyBase.ActiveEnemies`，后续换空间哈希）；子弹走池。
- `Projectile`：目标引用 + 距离判定（不是物理碰撞），目标死亡/超时回收。
- `EnemyBase`：FSM（Idle/Chase/Attack/Hurt/Die）+ Transform 移动 + 手工距离检测；`ApplyDifficulty` 按波次成长。
- `IDamageable`：统一受伤入口；伤害事件 `DamageDealtEvent` 驱动伤害数字/震屏/统计。

### 2.4 波次与难度
- `EnemySpawner`：`waveInterval` 开波，波内 `dripInterval` 滴灌刷新，`baseEnemiesPerWave + growth × (wave-1)` 数量增长，同屏上限 + 对象池。
- 难度：血量 `base + healthPerWave × wave`，移速 `base × (1 + speedPerWavePercent × wave)`。

### 2.5 局内成长
- `ExperienceGem`：磁吸（半径内加速飞向玩家）→ 拾取事件 → `PlayerExperience` 升级 → `LevelUpEvent`。
- `UpgradeSystem`：暂停 → 候选池随机抽 3（去重）→ `UpgradePanel` 展示 → 应用效果 → 恢复；效果通过玩家/武器公开方法应用。

### 2.6 游戏壳与流程
- `GameManager`：Menu/Playing/Paused/GameOver 状态机；`StartRun/RestartRun/GoToMenu/PauseGame/EndRun/ResumeRun`；场景重载时保留单例。
- `GameFlowController`：订阅玩家死亡 → 结算 → 发灵魂/记最佳 → 广告复活/重开/回菜单；Esc 暂停。
- `MainMenuController / TalentPanel / SettingsPanel`：完整菜单壳；`TalentEffects` 开局应用局外天赋。

### 2.7 存档与局外成长
- `SaveData`：设置 + 局外数据（灵魂、最佳记录、天赋等级、解锁列表）+ **版本号**。
- `SaveSystem`：`Application.persistentDataPath/save.json`；JsonUtility；读失败默认值兜底；`Migrate` 预留逐版本升级。
- `MetaProgression`：灵魂获取/消费、最佳记录、天赋读写。
- 面试追问：为什么不用 PlayerPrefs、迁移怎么做、损坏存档怎么处理、什么时候写盘（避免频繁 IO）。

### 2.8 商业化 Mock
- `IAdService.ShowRewardedAd(placement, onCompleted)`；
- `MockAdService` + `AdMockPanel`：3 秒倒计时（unscaled 时间）+ 关闭按钮（失败回调）；
- 复活：`PlayerHealth.Revive`（50% 血 + 2 秒无敌）+ `GameManager.ResumeRun`；
- 面试追问：广告位设计、复活触发时机与频控、激励视频成功/失败/关闭回调、真 SDK 接入时替换点。

### 2.9 数据与埋点
- `AnalyticsService`：本地事件计数 + 每局统计，存 `analytics.json`；
- `F1` 开发者数据面板展示局数/击杀/广告/升级选择/最佳记录；
- 面试追问：埋点字段怎么选、本地缓存与上报、怎么用数据调难度/商业化。

## 3. 性能目标与优化计划（待压测填数据）

| 指标 | 目标 | 测量方式 |
|---|---|---|
| 同屏敌人 | ≥ 200 稳定 60 FPS（1080p，本机实测） | Stats + Profiler |
| GC Alloc | 稳态 ≤ 0.5 KB/帧 | Profiler → GC Alloc |
| DrawCall | < 100 | Frame Debugger |
| 包体 | ≤ 200 MB（PC zip） | Build 报告（当前约 73 MB） |

**实测结果（2026-10-26，可复现）**

- 机器：Intel i7-11800H（8C16T）/ NVIDIA GTX 1050 Ti / 16 GB / Windows 11
- 条件：1280×720 窗口（**需前台**，Windows 会限制被遮挡窗口的渲染频率）、VSync off、**200 敌人同屏追击**（关闭玩家武器以隔离敌人负载、玩家无敌）存活 10 秒（预热 1 秒）
- 200 敌人结果：平均帧时间 **0.41 ms（≈2410 FPS 无上限）**；p50 0.38 ms、p95 0.60 ms、**p99 1.25 ms**；最差 5.79 ms；**平均 DrawCall 9**
- 规模曲线：

| 敌人数 | 平均帧时间 | p99 帧时间 | 平均 DrawCall |
|---|---|---|---|
| 50 | 0.27 ms | 0.99 ms | 9 |
| 100 | 0.28 ms | 0.82 ms | 9 |
| 200 | 0.41 ms | 1.25 ms | 9 |
| 300 | 0.57 ms | 1.48 ms | 9 |
| 500 | 0.75 ms | 1.36 ms | 9 |

- 结论：帧时间随敌人数线性增长，500 敌人时仍只有 60 FPS 预算（16.67 ms）的 1/22；DrawCall 恒定 9（Sprite 合批生效）
- 工具：`DungeonSurvivors.exe -stressTest -stressEnemies 200 -stressDuration 10 -screen-width 1280 -screen-height 720 -logFile stress.log`，输出 `stress_test_<N>.csv`；GC Alloc 用 Profiler 手动补
- 待补：GC Alloc（Profiler；2022.3 ProfilerRecorder 的 GC 计数器不可用）

优化路线：
1. 空间哈希网格替换 `ActiveEnemies` 线性索敌 + 敌人分离；
2. Sprite Atlas + 伤害数字合批；
3. 压测工具：一键生成 N 敌人 + 自动记录 FPS/GC/DrawCall 到 CSV；
4. 优化前后各记录一组 Profiler 数据，写进 README/技术文章。

## 4. 质量保障

- 编辑器一键场景生成：`Day0SceneSetup`（可重复执行、幂等）；
- 一键打包：`BuildScript.BuildWindows`；
- 后续补：Unity Test Framework EditMode 测试（伤害计算/对象池/存档迁移/升级池去重）。
- 命令行自检：
  ```powershell
  Unity.exe -batchmode -quit -projectPath "<project>" -executeMethod DungeonSurvivors.EditorTools.Day0SceneSetup.Run -logFile "Logs/setup.log"
  ```

## 5. 场景结构（Main.unity）

```
Main Camera      Orthographic, #0B0A12 背景, CameraFollow + CombatFeedback + AudioListener
Ground           Tiled SpriteRenderer（20×12）
Wall_*           四面围墙（BoxCollider2D）
GameManager      GameManager
PoolRoot         对象池父节点
Player           SpriteRenderer + Rigidbody2D + CircleCollider2D
                 PlayerController / DashAbility / PlayerHealth / PlayerExperience
                 MissileWeapon / UpgradeSystem / TalentEffects
EnemySpawner     EnemySpawner（波次）
GemSpawner       GemSpawner（经验掉落）
AdService        MockAdService
GameFlow         RunStats + GameFlowController
HUD              Canvas（HUD/Upgrade/Result/Pause/Ad/MainMenu/Talent/Settings/DevData）
```
