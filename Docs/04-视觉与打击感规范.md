# 视觉与打击感规范 v0.1（《地牢幸存者》）

> 来源：genre-scout 调研（`docs/research/visual-references.md`，10 款参考游戏截图已亲验）+ Lead 落地裁剪。
> 目标：作品集演示视频**前 10 秒抓眼球**；全部方案限定在 **Unity 2022.3 Built-in 2D**，不依赖 PPv2/URP。

## 1. 一句话视觉公式

> **近黑紫地牢底 + 只留 2 族高饱和强调色（暖橙火光 / 冷青魔法）+ 奶油白像素伤害数字 + 每一下攻击叠满「闪白 → 顿帧 → 震屏 → 击退 → 分层音效」五连。**

参考（主题最接近）：**Boneraiser Minions**（反派死灵法师 vs 勇者）、**Juicy Realm 恶果之地**（怪物 vs 人类）、Halls of Torment（地牢 + 割草）、Brotato（深底 + 白描边可读性）。

## 2. 调色板（写进 UI/美术规范）

| 用途 | 颜色 | 备注 |
|---|---|---|
| 背景/地面底 | `#0B0A12` 近黑紫 / `#241E33` 暗紫 | 相机背景已设为 `#0B0A12` |
| 高亮色 1 | `#FFB347` 橙白火光 | 攻击/爆炸/火把 |
| 高亮色 2 | `#3CE0C8` 青绿（或品红 `#FF4FD8`） | 魔法/变异/玩家技能 |
| 伤害数字 | `#FFF6E0` 奶油白 | 暴击金色 `#FFD34D`、受伤红 `#FF5A5A` |
| UI 描边 | `#D9A441` 暗金 | 面板/按钮统一描边 |
| 危险预警 | `#FF3B3B` | Boss/精英技能前摇红条 |

约束：**同屏只允许 2 族高饱和色**，其他全部低饱和；不同来源素材先统一到 16–24 色调色板（缝合素材变统一风格最有效的一步）。

## 3. 打磨优先级（按感知/成本比，落在 W2–W3）

| 优先级 | 内容 | 成本 | 实现要点 | 验收 |
|---|---|---|---|---|
| **P0** | 受击/击杀反馈五连：闪白 + 顿帧 30–50ms + 震屏 + 击退 + 分层音效 | 1.5–2 天 | 材质 `_FlashAmount` + `MaterialPropertyBlock`；`Time.timeScale=0` 用 `WaitForSecondsRealtime` 恢复；相机偏移按伤害分级 | 每次命中有明显"打到了"的感觉 |
| **P1** | 伤害数字系统（白/金/红分级 + 字号 + 池化） | 0.5–1 天 | 世界空间 Canvas + TMP + 对象池；上飘+缩放+淡出；暴击字号变大 | 同屏 200 个数字不掉帧 |
| **P2** | 3–4 层粒子 + 全屏白闪 | 1–1.5 天 | flash→sparks(additive)→debris→smoke 四层池化；Canvas 顶层白 Image alpha 0→0.8→0 | 击杀/升级时有"满屏爆炸"画面 |
| **P3** | 描边 + 压暗 + 暗角 | 1 天 | 描边 shader 或放大白色剪影 child；Canvas 径向渐变 overlay 压暗四周 | 150 只怪同屏也不糊 |
| **P4** | 镜头语言：zoom punch / 受伤红闪 / 低血心跳 / 击杀慢动作 | 0.5–1 天 | `orthographicSize` 缓动；红/白 overlay；`Time.timeScale=0.15` 0.2–0.4s | 视频里有"重量感" |

**不做**：强依赖 PPv2 全屏 Bloom（像素糊/WebGL 风险）、实时模糊/色差/扫描线（脏）、为特效牺牲帧率。

## 4. 前 10 秒分镜（演示视频用）

1. 0–1s：暗场，火把亮起（additive 光晕 flicker）；
2. 1–3s：勇者小队从入口涌入，主角小怪物在中央；
3. 3–5s：一发 AOE → 全屏白闪 + 顿帧 + 震屏 + 30 个伤害数字飞出；
4. 5–7s：割草连击，Combo 数字跳出，击杀勇者掉装备光柱；
5. 7–9s：升级慢动作 + 三张变异卡弹出，主角变色/长刺（形态变化）；
6. 9–10s：定格 Logo + 标题。

## 5. 参考游戏清单

Vampire Survivors、Brotato、Halls of Torment、**Boneraiser Minions**、20 Minutes Till Dawn、Dead Cells、Skul、Enter the Gungeon、**Juicy Realm 恶果之地**、Soul Knight；小游戏方向参考《向僵尸开炮》。
